    Kit 107

    只在 107 系列成立的內容。Isaac Sim 5.0.0(Kit 107.3.1)與 5.1.0(Kit 107.3.3)底下就是這一版,對應關係與出處見 01 §4。

    這一區的 0 篇。

    分區存在而內容為空,是因為分區判準是「結論依不依賴版本」:目前寫下的機制在 107 與 110 上都成立,所以都放在共通區。等到出現一條「只有 107 這樣、110 已經不是」的結論,才會落到這裡。

    要從 107 升上去的話,官方列出的移除與棄用項整理在 11 從 Kit 107 升到 110。那篇放在 110 區,因為讀者是要升上去的人。

    107 本身值得先記住的一件事:omni.kit.window.viewport 在 Kit 106 標為 deprecated,到 107 已從 SDK 移除。針對 106 寫的程式碼搬到 107 會在這裡斷掉。這條目前只有官方 release notes 的說法,本 repo 未實機驗證,列在 11 §6 第 5 條。
