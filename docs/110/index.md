# Kit 110

只在 110 系列成立的內容。Isaac Sim 6.0.0 GA(Kit 110.1.1)與 6.0.1(Kit 110.1.2)底下是這一版,對應關係與出處見 [01 §4](../common/01-kit-is-the-framework/README.md)。

這一區的 0 篇。

分區存在而內容為空,理由與 [107 區](../107/)相同:目前寫下的機制兩版都成立,就留在[共通區](../common/)。

版本號從 107 跳到 110,中間的 109 只出現在 Isaac Sim 6.0 的早期開發版,沒有對應的正式產品線。看到不連續不用回頭找。
